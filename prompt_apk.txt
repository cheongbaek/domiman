이 파일을 활용하여 ntfy 원격 제어가 가능한 안드로이드 앱을 만들 것이다.

안드로이드 앱 구현방법
<첫 화면>
(로그인 화면이 뜬다.)
(제목으로 크게 'DOMIMAN' 이라고 적혀있을 것.)
이 앱은 ntfy를 통한 원격 낚시 제어 프로그램입니다. ntfy 메시징에 사용될 ID와 채널명을 입력해주세요.
ID [         ]
ntfy 채널 이름 [        ]
채널 이름은 실제 PC의 도미맨이 사용중인 채널을 적어주세요.
[*] ID 기억하기 [*] 채널이름 기억하기
[*] 자동 로그인
[로그인]

(이러한 화면이 뜨도록 한다. ID 기억하기와 채널이름 기억하기 쪽 체크박스를 선택하면 이후 앱을 껐다 켜고 그 이름이 그대로 남아있도록 한다. 자동 로그인 체크박스를 선택하면 앱을 껐다 켜도 직전의 ID와 채널이름을 가지고 앱을 실행하자마자 로그인 후 다음 화면으로 넘어간다.
로그인 버튼을 누르면 domiman.py와 유사하게 15초 텀으로 응답을 주고받는다. 실패하면 '실패하였습니다. 다시 시도해주세요'라는 알림을 띄우고 돌아간다. 성공하면 다음 화면으로 넘어간다.

<로그인 후 제어화면>
PC의 GUI환경과 유사하게 배치한다.
[ (제어하고자 하는 PC이름) ]
해상도  1920 x 1080 (자동 감지됨)
타이머  0
0을 입력하면 살림망 감시 모드로 작동합니다.
[v] ntfy 메시지
[ ] 낚싯대 자동교체
[v] 미끼 자동교체       (---이 둘 역시 타이머 값에 따라 숨기고 말고가 결정된다.)
낚싯대, 미끼 자동교체는 살림망 감시 모드에서만 사용 가능합니다.
[(큼지막하게) 시작/중지]
[예약 종료] [즉시 회수]
로그           [vvv][x]
[다크모드] [프로그램 종료]
알림 설정
[v] 상태 문구 (이것을 켜야 하단 작은 알림이 뜸)
[ ] 낚시 루틴 시작 시
[v] 낚시 루틴 실패 시
[ ] 낚싯대 교체 성공 시
[v] 낚싯대 교체 실패 시
[ ] 미끼 교체 성공 시
[v] 미끼 교체 실패 시
[v] 게임이 튕길 경우
(위의 체크표시가 기본값으로 둔다. 기능은 말 그대로. 상태문구를 제외한 나머지 기능들은 휴대폰 푸쉬알림으로 온다. 권한 허용이 필요할 것으로 예상된다)
[로그아웃]
세로모드 시에는 이 순서로 배치하며 가로모드 시에는 PC버전과 동일하게 배치하되 SMS 메시지 체크박스 생략, 'ntfy/SMS에 표시될 이름'과 'ntfy  채널 이름' 글자와 입력란은 생략한다. 이는 로그인 단계에서 입력하도록 되어 있다. 대신 그 자리에 [로그아웃] 버튼이 들어간다.
'로그아웃' 버튼을 누르면 첫 화면으로 돌아간다. '다크모드' 버튼을 누르면 역시 PC처럼 적절히 색을 바꾸도록 하되 PC와 다르게 현재 휴대폰이 다크모드인지 화이트모드인지 감지하여 이에 맞춰 앱 색상을 두며 만일 인위적으로 버튼을 눌러 색을 바꾸면 껐다 켜도 그 값이 남아있도록 한다.
상태 문구는 PC와 다르게 안드로이드 상의, 특별한 버튼 없이 4초 뒤 사라지는 화면 하단의 작은 알림으로 띄운다.
로그도 PC와 유사하게 ntfy값을 뿌리도록 하되 로그 내보내기 기능이나 로그 저장 기능은 없다. 기본적으로는 숨김 상태이다.
'프로그램 종료' 버튼을 누르면 피제어 PC의 domiman이 종료된다.
자동로그인, 다크모드 등에 사용되는 저장값은 앱 캐시 삭제(데이터 삭제) 시에 지워지도록 한다. 로그인화면과 제어화면 모두 가로/세로모두에 대응되도록 한다.
안드로이드에서만 작동되도록 하면 되며 파이썬이 좋긴 하겠지만 구현상에 있어 다른 언어를 사용하더라도 ntfy 통신, 안드로이드 APK 포팅, VS Code에서 작업이 가능하다면 다른 언어를 사용해도 된다.
